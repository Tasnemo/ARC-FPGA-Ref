  • Standalone build (loaded with load_board): connect to the USB-serial adapter on Pmod JE, not the Zybo's own USB port. Still nothing? Flip SW3 (swaps TX and RX on JE).
  • Mac: the Zybo shows up as two ports (e.g. …usbserial-210279A and …B, or two "Digilent Adept USB Device" entries). The UART is usually the second one. Disconnect and pick the other.
  • Windows: pick the COM port for "USB Serial Port". If none appears, install the FTDI VCP driver (see README).
  • Check the board is running the referee: green DONE LED on, and LD3 flashes when you press a button here. If the board text below says "core not found", the bitstream is missing.
